# Texture attribution

Planetary textures by Solar System Scope / INOVE, from https://www.solarsystemscope.com/textures/.
Licensed under Creative Commons Attribution 4.0 International (CC BY 4.0): https://creativecommons.org/licenses/by/4.0/.

This project includes optimized derivatives:

- earth-day.webp — 2k_earth_daymap.jpg, Earth at home and contact (2048 × 1024).
- earth-clouds.webp — 2k_earth_clouds.jpg, Earth's separate cloud shell (1024 × 512).
- mars.webp — 2k_mars.jpg, Accenture's Mars scene (2048 × 1024).
- jupiter.webp — 2k_jupiter.jpg, iConsult's Jupiter scene (2048 × 1024).
- moon.webp — 2k_moon.jpg, Jupiter knowledge moons, TenantLens service moons/platform, diploma outpost, and skill asteroid materials (1024 × 512).

Changes: WebP re-encoding, downsampling of clouds, color tinting for fictional bodies, and application of the Moon map to deformed asteroid geometry. The Moon mirror was already downsampled to 1K. No endorsement by Solar System Scope or INOVE is implied.

Sources were retrieved through public mirrors using read-only connector access because direct shell downloads were restricted. Original Solar System Scope download URLs, mirror locations, Git blob identifiers, dimensions, and output sizes are recorded in manifest.json. Earth day/cloud files are mirrored by elymas/solar-simulator; Mars/Jupiter by pjcigan/skyplothelper; Moon by homer-jay/solar-system-textures. The mirrors explicitly identify these files as Solar System Scope CC BY 4.0 assets.

These texture derivatives retain CC BY 4.0. No additional restrictions are imposed on the assets. The original source images are not bundled. All five runtime maps are local, require no external image host, and total 731,970 bytes.
